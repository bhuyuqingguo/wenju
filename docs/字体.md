# 字体回退与授权

无敌公文体的正文首选「仿宋_GB2312」。本机没有时改用「仿宋」。docx 里写的是实际选中的家族名。两个都没有时，仍写下「仿宋_GB2312」，并在启动时提示。

| 首选 | 本机常见家族名 | 英文名 / 文件 | 能否放进程序包 |
| --- | --- | --- | --- |
| 仿宋_GB2312 | Windows：仿宋_GB2312 | FangSong_GB2312，常见文件 simfang.ttf | 不能。中易字体随系统或 Office 授权 |
| 仿宋 | Windows 10+、麒麟：仿宋 | FangSong | 不能。随系统授权 |
| 楷体_GB2312 | 楷体_GB2312 | KaiTi_GB2312 | 不能 |
| 黑体 | 黑体 | SimHei | 不能 |
| 宋体 | 宋体 | SimSun | 不能 |
| 方正小标宋简体 | 方正小标宋简体 | FZXiaoBiaoSong-B05S | 不能。方正商用 |
| 思源宋体 / 思源黑体 | Noto Serif SC / Noto Sans SC | OFL | 可以，但要单独做字体包，不放进程序包 |

字体包和程序包分开。把自有字体放在程序旁的「可选字体」文件夹。Windows 10 及以上可以装到当前用户目录并写 HKCU。Windows 7 没有用户级字体，只在文矩进程里加载，不写注册表。Linux 复制到 `~/.local/share/fonts` 后执行 `fc-cache`。
